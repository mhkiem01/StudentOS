Required format

Main AI import

Topic: [Topic Name]\nQuestion: [Question text]\nAnswer choices:\nA. [Option 1]\nB. [Option 2]\nC. [Option 3]\nD. [Option 4]\nE. [Optional extra choice]\nAnswer: A\nExplain: [Explanation]

Use Answer: A for one correct choice or Answer: C, E for multiple. One letter creates radio choices; multiple letters create checkboxes. When adding questions from a topic's ••• menu, Topic: is not required.

Generate exam-style multiple-choice questions for my study.\n\nCreate questions for these topics:\n- [Topic 1]\n- [Topic 2]\n- [Topic 3]\n\nUse this EXACT format for every question:\n\nTopic: [Topic Name]\nQuestion: [Question text]\nAnswer choices:\nA. [Option 1]\nB. [Option 2]\nC. [Option 3]\nD. [Option 4]\nE. [Optional extra choice]\nAnswer: A\nExplain: [Clear explanation]\n\nRules:\n- Create 10 questions per topic.\n- Use consecutive answer labels starting at A.\n- For one correct choice, use one letter, such as Answer: A.\n- For multiple correct choices, use comma-separated letters, such as Answer: C, E.\n- Keep topic names consistent.\n- Start each question with Topic:.\n- You may use i., ii., iii., iv. statements underneath Question:.\n- Do not use markdown tables.
Multiple statements

i / ii / iii / iv example

Topic: Language Fundamentals\nQuestion: Which statements correctly describe consonants?\ni. They involve some restriction of airflow.\nii. They may occur at the start or end of syllables.\niii. They are always unvoiced.\niv. They differ from vowels.\n\nAnswer choices:\nA. i, ii, iii\nB. i, ii, iv\nC. ii, iii, iv\nD. i, iii, iv\n\nAnswer: B\nExplain: Statements i, ii and iv are correct. Statement iii is false because some consonants are voiced.
Roman numerals belong inside the question. The final selectable answer remains A, B, C or D.
